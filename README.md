# CampusFix — Smart Campus Issue Reporting

A beginner-friendly hackathon prototype for reporting campus problems, automatically classifying them into categories, estimating priority, and tracking resolution status.

## Run
No installation required.
1. Download/clone the repository.
2. Open `index.html` in a browser.
3. Submit sample issues such as:
   - "Water leakage near Block A"
   - "WiFi not working in lab"
   - "Garbage not collected near hostel"
4. The dashboard automatically assigns a category and priority.

## Tech stack
- HTML
- CSS
- JavaScript
- Browser LocalStorage

## Core idea
The current prototype uses transparent keyword-based smart triage so it works without an API key. A future version can replace this module with an ML/LLM classifier, add a real backend/database, admin login, duplicate detection, notifications and analytics.
